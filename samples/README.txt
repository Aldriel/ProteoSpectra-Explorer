ProteoSpectra-Explorer - Fichiers d'exemple / Sample files
=============================================================

FRANÇAIS
--------
Ouvrez ces fichiers dans l'onglet « Spectres » avec « Ouvrir un fichier JSON... »
(ou Fichier > Ouvrir un fichier de spectres..., Ctrl+O), puis sélectionnez un spectre
et cliquez sur « Annoter ». Le guide complet est dans l'application : Aide > Guide
d'utilisation (F1), section « Fichiers d'exemple ».

  01-demo-peptides.json               3 spectres identifiés (PEPTIDE, ELVISLIVESK, SAMPLER)
  02-hemoglobin-alpha-tryptic.json    6 peptides trypsiques de l'hémoglobine alpha (UniProt P69905)
  03-ptm-modifications.json           peptides modifiés (acétyle, oxydation, phospho...)
  04-pride-proxi-VLHPLEGAVVIIFK.json  spectre réel du projet PRIDE PXD000561, format PROXI
  05-unidentified-spectra.json        3 spectres sans identification : exercice d'identification
  06-peak-formats.json                les trois façons d'écrire les pics (modèle pour vos fichiers)
  07-parsing-errors.json              entrées invalides : comparer les modes Tolérant et Strict

Les fichiers 01, 02, 03 et 05 sont synthétiques (pics calculés, erreur de quelques ppm,
ions manquants et bruit). Le fichier 04 est un spectre public réel (EMBL-EBI PRIDE).

ENGLISH
-------
Open these files in the "Spectra" tab with "Open JSON file..." (or File > Open spectrum
file..., Ctrl+O), then select a spectrum and click "Annotate". The full guide is in the
application: Help > User guide (F1), "Sample files" section.

  01-demo-peptides.json               3 identified spectra (PEPTIDE, ELVISLIVESK, SAMPLER)
  02-hemoglobin-alpha-tryptic.json    6 tryptic peptides of hemoglobin alpha (UniProt P69905)
  03-ptm-modifications.json           modified peptides (acetyl, oxidation, phospho...)
  04-pride-proxi-VLHPLEGAVVIIFK.json  real spectrum from PRIDE project PXD000561, PROXI format
  05-unidentified-spectra.json        3 spectra without identification: identification exercise
  06-peak-formats.json                the three ways to write peaks (template for your own files)
  07-parsing-errors.json              invalid entries: compare Lenient and Strict modes

Files 01, 02, 03 and 05 are synthetic (computed peaks, a few ppm of error, missing ions
and noise). File 04 is a real public spectrum (EMBL-EBI PRIDE).
